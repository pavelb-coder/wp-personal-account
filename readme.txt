Личный кабинет пользователя с конструктором: профиль, пароль, смена email, команды, вход и регистрация на шорткодах.

== Description ==

Плагин создаёт полноценный личный кабинет на обычной странице WordPress — без конструкторов и сторонних фреймворков.

Возможности:

* Отдельная панель управления в wp-admin: меню «Личный кабинет» с обзором, аккаунтами и инструментами.
* Обзор: пользователи, новые регистрации за 30 дней, график регистраций за 14 дней, состояние интеграций.
* Аккаунты: поиск, фильтр по роли, команда пользователя, незавершённые подтверждения email.
* Команды: список команд, капитаны, состав, редактируемый лимит участников для каждой команды, роспуск из админки.
* Конструктор кабинета: вкладки собираются из блоков — включение, порядок, свои заголовки, аудитория, произвольные HTML-блоки.
* Инструменты: восстановление страницы кабинета, сброс блокировок входа, очистка заявок на смену email, экспорт CSV.
* Вкладки кабинета: «Обзор», «Профиль», «Команда», «Безопасность».
* Команды: объединение нескольких аккаунтов — капитан создаёт команду, приглашает участников ссылкой (7 дней) или письмом, исключает их и распускает команду; участник может выйти сам.
* Профиль: имя, фамилия, отображаемое имя, «о себе».
* Смена пароля с проверкой текущего пароля.
* Смена email с подтверждением по ссылке из письма (токен, срок 24 часа).
* Блок Gutenberg «Вход и регистрация (личный кабинет)» — для блочных тем и Site Editor.
* Виджет «Личный кабинет: вход и регистрация» для главной страницы и сайдбаров: переключатель «Вход / Регистрация», настройка режима, редирект, скрытие от авторизованных.
* Формы входа и регистрации: nonce, лимит попыток входа, проверка пароля, согласие на обработку данных.
* Тёмных тем не боится: стили изолированы префиксом `wppa`, акцентный цвет настраивается.
* Переопределение шаблонов в теме: `yourtheme/wp-personal-account/{шаблон}.php`.
* Блоки конструктора переопределяются в теме, свой блок добавляется фильтром `wppa_blocks`.
* Все строки переводимы, текстовый домен `wp-personal-account`.

== Installation ==

1. Загрузите папку плагина в `/wp-content/plugins/` (или установите ZIP через «Плагины → Добавить новый»).
2. Активируйте плагин — страница «Личный кабинет» со шорткодом `[wppa_account]` создастся автоматически.
3. Проверьте настройки: «Настройки → Личный кабинет».

== FAQ ==

= Есть ли интеграция с WooCommerce? =
Нет. Начиная с версии 2.0.0 плагин не зависит от WooCommerce: разделы «Заказы» и «Адреса» удалены, остались профиль, безопасность и вход/регистрация.

= Работает ли без ЧПУ? =
Да. Навигация построена на query-аргументах (`?wppa_tab=orders`), поэтому постоянные ссылки не обязательны.

= Как переопределить шаблон? =
Скопируйте файл из `wp-personal-account/templates/` в `ваша-тема/wp-personal-account/` и правьте копию.

= 2.1.0 =
* Новая вкладка «Команда»: объединение нескольких аккаунтов в одну группу.
* Капитан команды: переименование, ссылка-приглашение (7 дней), приглашение по email, исключение участников, роспуск команды.
* Участник: просмотр состава, самостоятельный выход из команды.
* Вход по коду из приглашения прямо во вкладке, если ссылка не открывается.
* Настройка «Максимум участников» (2–100, по умолчанию 10) и индивидуальный лимит для каждой команды.
* Настройка «Минимум участников» (1–100, по умолчанию 2) и индивидуальный минимум для каждой команды; команды ниже минимума помечаются «недобор».
* Отдельные блоки Gutenberg «Вход» (`wppa/login`) и «Регистрация» (`wppa/register`): форма или кнопка-ссылка.
* Выгрузка аккаунтов в сетевую папку (SMB) по расписанию: те же группы колонок, ротация файлов и журнал запусков.
* Своё восстановление пароля: заявка по логину или email и установка нового пароля в кабинете, без перехода на wp-login.php.
* Экспорт аккаунтов в CSV по группам колонок: учётная запись, профиль, личные данные, команда, статусы — с фильтрами и выбором разделителя.
* Панель WordPress (админ-бар) скрывается в личном кабинете — на странице кабинета, с шорткодом [wppa_account] или блоком кабинета.
* Регистрация по таймеру: приём заявок открывается и закрывается по расписанию, кнопка «Регистрация» до открытия неактивна и показывает отсчёт.
* Настройка «Требовать наставника»: команда без наставника считается несформированной — в кабинете, в админке и в условии кнопки со ссылкой.
* Блок «Кнопка со ссылкой»: внешняя ссылка открывается в заданном периоде дат и только когда команда набрана до минимума; до этого — неактивная кнопка с обратным отсчётом.
* Проверка пароля по 10 параметрам: длина (16), заглавные и строчные буквы, цифры, спецсимволы, разнообразие символов, повторы, последовательности, словарь частых паролей, персональные данные (email, логин, имя).
* Список требований под полем пароля подсвечивается по мере ввода; правила включаются в настройках.
* Обязательные поля помечены звёздочкой: email, пароли, имя, согласие.
* Настройка внешнего вида блоков: оформление (карточка / рамка / без оформления), ширина, размер кнопок, акцентный цвет, радиус, плюс штатные панели цветов, отступов, рамки и типографики.
* Кнопка «Регистрация» под формой входа (и «Войти» под формой регистрации); в виджете в режиме «оба» кнопка не дублирует вкладки.
* Роль наставника в команде: капитан (или администратор) назначает наставника — участника с правом приглашать и исключать участников. Наставник не считается участником и не занимает место в лимите.
* Персональные данные в регистрации и профиле: имя, фамилия, отчество, телефон, дата рождения, город, организация, должность, сайт, Telegram, о себе — каждое поле можно включить и сделать обязательным.
* Валидация телефона, даты рождения и сайта; персональные данные видны в админке и выгружаются в CSV.
* Админ-панель: раздел «Команды» со списком, капитанами и составом, карточка метрик на «Обзоре», колонка «Команда» в «Аккаунтах» и в экспорте CSV.
* При обновлении вкладка «Команда» включается автоматически (миграция настроек).

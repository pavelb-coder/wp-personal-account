Личный кабинет пользователя с конструктором: профиль, пароль, смена email, команды, вход и регистрация на шорткодах.

== Description ==

Плагин создаёт полноценный личный кабинет на обычной странице WordPress — без конструкторов и сторонних фреймворков.

Возможности:

* Отдельная панель управления в wp-admin: меню «Личный кабинет» с обзором, аккаунтами и инструментами.
* Обзор: пользователи, новые регистрации за 30 дней, график регистраций за 14 дней, состояние интеграций.
* Аккаунты: поиск, фильтр по роли, команда пользователя, незавершённые подтверждения email.
* Команды: список команд, капитаны, состав, лимит участников, роспуск из админки.
* Конструктор кабинета: вкладки собираются из блоков — включение, порядок, свои заголовки, аудитория, произвольные HTML-блоки.
* Инструменты: восстановление страницы кабинета, сброс блокировок входа, очистка заявок на смену email, экспорт CSV.
* Вкладки кабинета: «Обзор», «Профиль», «Команда», «Безопасность».
* Команды: объединение нескольких аккаунтов — капитан создаёт команду, приглашает участников ссылкой (7 дней) или письмом, исключает их и распускает команду; участник может выйти сам.
* Профиль: имя, фамилия, отображаемое имя, «о себе».
* Смена пароля с проверкой текущего пароля.
* Смена email с подтверждением по ссылке из письма (токен, срок 24 часа).
* Блок Gutenberg «Вход и регистрация (личный кабинет)» — для блочных тем и Site Editor.
* Виджет «Личный кабинет: вход и регистрация» для главной страницы и сайдбаров: переключатель «Вход / Регистрация», настройка режима, редирект, скрытие от авторизованных.
* Формы входа и регистрации: nonce, лимит попыток входа, проверка пароля, согласие на обработку данных.
* Тёмных тем не боится: стили изолированы префиксом `wppa`, акцентный цвет настраивается.
* Переопределение шаблонов в теме: `yourtheme/wp-personal-account/{шаблон}.php`.
* Блоки конструктора переопределяются в теме, свой блок добавляется фильтром `wppa_blocks`.
* Все строки переводимы, текстовый домен `wp-personal-account`.

== Installation ==

1. Загрузите папку плагина в `/wp-content/plugins/` (или установите ZIP через «Плагины → Добавить новый»).
2. Активируйте плагин — страница «Личный кабинет» со шорткодом `[wppa_account]` создастся автоматически.
3. Проверьте настройки: «Настройки → Личный кабинет».

== FAQ ==

= Есть ли интеграция с WooCommerce? =
Нет. Начиная с версии 2.0.0 плагин не зависит от WooCommerce: разделы «Заказы» и «Адреса» удалены, остались профиль, безопасность и вход/регистрация.

= Работает ли без ЧПУ? =
Да. Навигация построена на query-аргументах (`?wppa_tab=orders`), поэтому постоянные ссылки не обязательны.

= Как переопределить шаблон? =
Скопируйте файл из `wp-personal-account/templates/` в `ваша-тема/wp-personal-account/` и правьте копию.
